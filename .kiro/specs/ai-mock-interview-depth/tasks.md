# Implementation Plan: AI Mock Interview Depth

## Overview

Enhance the existing AI Mock Interview module with three depth layers: voice I/O (browser Web Speech APIs wrapped in custom React hooks), a real-time live score panel, and a detailed post-interview report generated by Gemini with a local fallback. The implementation is entirely additive — no existing API contracts are broken. Backend changes land first (schema, controller normalization, new report endpoint, route registration), followed by frontend hooks, components, and finally wiring everything together in `MockInterview.jsx`.

## Notes

- Tasks marked with `*` are optional and can be skipped for a faster MVP
- Each task references specific requirements for traceability
- Checkpoints (tasks 6, 11, 15) ensure incremental validation at natural boundaries
- Property tests use **fast-check** (minimum 100 iterations each); unit tests use Vitest (frontend) and Jest (backend)
- The `report` route (`GET /mock-interview/:id/report`) must be registered **before** `GET /mock-interview/:id` in `api.js` to prevent Express from matching the literal string `"report"` as the `:id` parameter
- `recharts` is already in `frontend/package.json` — no additional install needed for the bar chart in `InterviewReport`
- `mongodb-memory-server` will need to be installed for integration tests: `npm install --save-dev mongodb-memory-server` in `backend/`
